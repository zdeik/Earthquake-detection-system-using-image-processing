📌 CCTV 기반 구조물 흔들림 감지 시스템

A Frame-Diff 기반 Real-Time Vibration Detection System (LLM 이전 시대 개발)

본 프로젝트는 CCTV 영상 프레임의 변화량을 기반으로 구조물의 비정상적 흔들림을 감지하는 시스템입니다.
딥러닝이나 LLM 모델 없이 개발되었으며, 경량·고속·저비용을 목표로 한 전통 컴퓨터비전 기반 알고리즘으로 구현되었습니다.

🚀 프로젝트 개요

지진이나 강한 진동 상황에서 CCTV 자체가 흔들릴 경우 건물 구조물의 안전성을 판단하는 보조 지표가 될 수 있습니다.
본 시스템은 실시간으로 CCTV 프레임을 입력받아 이전 프레임과 비교하고, 오차 범위를 초과하는 변위가 감지되면 흔들림으로 판단합니다.

사람·차량 등 일시적 객체 움직임은 감지 대상에서 제외되며, 화면 전체적으로 발생하는 구조물 단위의 흔들림만 추출하도록 설계되었습니다.

🛠 주요 기능
✅ 1. 실시간 프레임 흐름 분석

CCTV에서 들어오는 연속적인 프레임을 지속적으로 수집

프레임 간 차이를 계산하여 움직임 발생 여부 판단

✅ 2. 구조물 흔들림 전용 감지

작은 물체(사람, 차량 등) 움직임은 노이즈로 처리

화면의 넓은 영역에서 발생하는 동시적 변화에 집중

고정된 구조물의 흔들림만 감지하는 로직 적용

✅ 3. 오차 범위 기반 Threshold 판단

일정 오차 범위 내의 진동은 무시

임계값을 초과할 경우 흔들림 이벤트 발생

✅ 4. 경량 알고리즘

딥러닝 없이 C++ 기반 간단한 영상 처리만으로 동작

지연 없이 실시간 분석 가능

저사양 환경(CCTV Edge Device)에서도 사용 가능

🧠 사용된 알고리즘
▶ Frame Difference Algorithm
diff = abs(current_frame - previous_frame)
if diff > threshold:
    흔들림 감지

▶ Background Modeling (약식)

시간이 지나도 변하지 않는 영역을 배경으로 간주

작은 객체 움직임 제거

넓은 범위 움직임만 남겨 구조물 흔들림만 분석

▶ Global Motion Estimation(유사 방식 적용)

움직임이 전체 화면에서 동시에 발생할 경우 “흔들림”으로 판단

국소 영역만 변화하는 경우(사람/차량)는 무시 처리

🏢 실제 환경 적용 시 고려 사항

현장 환경(CCTV 설치 위치, 조도, 화질)에 대응하기 위해 다음 개선이 필요할 수 있습니다:

조도 변화 대응(광량 급변 → 흔들림 오탐 방지)

카메라 자체 진동과 구조물 진동 분리

CCTV 설치 각도 보정

다중 CCTV 연동 시 신뢰도 향상 로직
예: 동일 건물 내 여러 CCTV에서 동시에 흔들림 발생 시 진동으로 판단
